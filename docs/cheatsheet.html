qSFC cheat sheet

One element per line, in the order you write a chart. Keywords are case-insensitive; indentation is only for reading. More: Help → Learning qSFC and Reference.

1 · A chart

init idleinitial step (one per chart)

2 · Actions

valve [:=] 1;ST under the step; back to 0 when it ends
count := 0;keeps its value
on pump, fanon while the step is active
set alarm · reset alarmlatch on / off
step heat
  on heater        // N: lines before a qualifier
  S                // stored until R
    door_lock := 1;
  L 5s             // limited
    buzzer [:=] 1;
  D 2s             // delayed
    light [:=] 1;
  P                // once
    cycles := cycles + 1;

3 · Time and step members

fill.done · fill.DNpreset elapsed
fill.active · fill.Xstep active
fill.time · fill.Tms active
fill.first · fill.FSfirst scan
fill.Counttimes activated
-- after 5sthe step above active 5 s

Durations: 500ms 5s 2m 1h 1m30s (a unit is required).

4 · Branches

step check
select
  -- ok
  step pack
  -- packed
|
  -- NOT ok
  step reject
  -- out -> idle
end
step next
-- go
parallel
  step fill_a
|
  step fill_b
end
-- level_a AND level_b

select: after a step; one leg runs (first true). parallel: after a transition; all legs run, the transition after end waits for all.

6 · Program

controller              // shared tags
  tag stop : BOOL = 1
  sfc tags fill
end
program tank "Title"
uses INIT, Main (main)   // not in this file

st main                 // first routine: runs every scan
  call fill_seq;
sfc fill_seq
init idle
  SFR(other, start);      // reset a chart
  SFP(other, Pause);      // pause / Execute
-- go -> idle

Names: letters, digits, _; at most 40; shared by steps, transitions, tags and routines. s3 keeps number 3 on export, tr5: number 5.
