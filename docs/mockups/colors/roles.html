  • 2 · Structure cool, behavior warm: The chart's skeleton in cool colors (steps blue, transitions teal, branches indigo); what it does in warm ones (actions orange, time ochre, values rose).

  • 5 · Color-blind safe (E): Four Okabe-Ito hues; time takes its step's color in italic, values are italic text.

Part 2 · Should transitions get a structure hint too?

  • a · Steps only: Step lines get a tinted band and a bar; transitions get nothing more than their blue --.
  • b · Transition bar: Transitions get a thin blue bar in the margin, under the step's thick amber one.
  • c · Transition band: Transitions get their own light blue band: the file alternates amber and blue lines like the chart alternates steps and transitions.
  • d · Chart symbols in the margin: A small symbol before each structure line, like the diagram: □ step, ▣ initial step, ━ transition, ┆ select, ═ parallel. No bands.
  • e · S / T column (your idea): A narrow column left of the line numbers: S on each step (underlined for the initial step), T on each transition, ┆ ═ on branch lines. The code itself stays plain: the column alone shows the chart's rhythm.
  • f · Numbered S1… / T1…: The same column, numbered in file order like the diagram's step numbers (View → Step numbers): S3 in the code is step 3 in the diagram.
  • g · Step blocks: A step and its action lines form one tinted block; each transition sits between two blocks on thin blue rules.
